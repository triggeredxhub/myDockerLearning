docker pull - from yesterday 

docker run <image> - you can skip the "docker pull" and proceed with docker, if the image is not locally present it will proceed the download

docker run -d <image>  - this will not ocupy the terminal, the output only will be the container ID

docker ps - check running container

docker logs <containerId> - from the previous step this command will show the logs of the container
